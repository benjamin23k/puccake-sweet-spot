# Puccake Sweet Showcase

Quiero crear una página web profesional, moderna y visualmente atractiva para una tienda de repostería llamada "Puccake".

IMPORTANTE:

Voy a proporcionar el logo de Puccake como referencia visual. El diseño completo de la página debe construirse alrededor de este logo y respetar estrictamente su identidad visual, estilo, formas y paleta de colores.

NO quiero una página genérica de pastelería.

Quiero que parezca una marca real, cuidada y lista para vender.

========================================

IDENTIDAD DE MARCA

========================================

Nombre de la marca:

PUCCAKE

Concepto:

Una tienda de repostería, dulces y postres con una identidad cute, elegante, juvenil y ligeramente premium.

El logo tiene como elementos principales:

- Fondo crema cálido.

- Tipografía "PUCCAKE".

- Letras con combinación de rojo, naranja y amarillo/dorado.

- Personaje ilustrado estilo cute/kawaii.

- Un vaso/postre con frutas y crema.

- Detalles negros y rojos en el personaje.

La interfaz debe tomar inspiración directamente de estos elementos.

Paleta visual aproximada:

- Cream principal: #FFE7C3

- Cream secundario: #FDF0D5

- Rojo principal: #D71920

- Rojo oscuro: #A90F16

- Naranja/dorado: #F2A23A

- Amarillo cálido: #F5B94C

- Negro carbón: #29292C

- Marrón cálido para detalles: #624F3D

- Blanco cálido: #FFF9F0

Usar los colores crema como base predominante.

Utilizar rojo, naranja y dorado como colores de acento.

Utilizar negro carbón para textos importantes.

Evitar colores que choquen con la identidad de la marca, especialmente azul, verde neón, morado intenso o colores fríos.

No saturar la interfaz de rojo.

La combinación debe sentirse elegante y equilibrada.

========================================

- Animación ligera de botones.

- Transiciones suaves.

- Entrada elegante de las secciones.

No hacer que toda la página esté flotando o moviéndose constantemente.

========================================

TIPOGRAFÍA

========================================

Utilizar una combinación de tipografías que conserve el carácter cute/premium de Puccake.

Los títulos pueden tener una tipografía con personalidad ligeramente redondeada.

El texto general debe utilizar una sans-serif moderna y altamente legible.

Mantener una jerarquía tipográfica clara.

========================================

DISEÑO DEL FONDO

========================================

El fondo principal debe utilizar tonos crema cálidos.

Utilizar diferentes tonos crema para separar visualmente las secciones.

Por ejemplo:

Hero:

Cream

Productos:

Warm White

Categorías:

Light Cream

Promociones:

Cream + Red accent

Footer:

Dark charcoal

Evitar que toda la página tenga exactamente el mismo color de fondo.

========================================

DETALLES DE BRANDING

========================================

El logo debe ser el elemento principal de identidad.

NO modificar el logo.

NO cambiar sus colores.

NO recrear el personaje con otro estilo.

NO sustituir el logo por texto genérico.

Utilizar el logo proporcionado como referencia visual y mantener su apariencia original.

Los elementos decorativos de la interfaz deben complementar al personaje del logo.

La página debe sentirse como si el personaje del logo perteneciera naturalmente al universo de la tienda.

========================================

EXPERIENCIA DE USUARIO

========================================

El usuario debe poder:

1. Entrar a Puccake.

2. Ver inmediatamente qué vende la tienda.

3. Explorar categorías.

4. Ver productos.

5. Abrir los detalles de un producto.

6. Agregar productos al carrito.

7. Personalizar cantidades/opciones.

8. Revisar el carrito.

9. Realizar el pedido.

10. También poder pedir directamente por WhatsApp.

El proceso de compra debe tener la menor fricción posible.
